title: Scripts

---

Dear Pages uses several **npm** scripts to simplify common development, verification, and documentation tasks.

The main application scripts are defined in the root `package.json`.

## Start the development server

```bash
npm run dev
```

This command starts the Vite development server.

It lets you work on the application locally with automatic reload when the code changes.

## Build the application

```bash
npm run build
```

This command generates an optimized production version of Dear Pages.

Vite creates the files required for deployment.

This command is also used to check that the application can be built correctly before deployment.

## Preview the build

```bash
npm run preview
```

This command runs locally the version generated by `npm run build`.

It is useful to check production behavior before deployment.

## Check code with ESLint

```bash
npm run lint
```

This command analyzes the source code with ESLint.

It can detect some errors, inconsistencies, or problematic patterns before build or deployment.

## Run tests

Dear Pages uses Vitest for automated tests.

```bash
npm run test
```

This command runs the project's test suite.

Tests cover important parts of the application such as:

- services;
- utilities;
- hooks;
- components;
- important interactive behavior.

They complement manual checks on the main user flows.

## Generate JSDoc documentation

Dear Pages also has a script to automatically generate technical documentation from JSDoc comments in the code.

```bash
npm run docs
```

The corresponding script is:

```json
"docs": "jsdoc src -r -d docs"
```

JSDoc recursively analyzes the `src` folder and generates documentation in:

```text
docs/
```

This folder is generated automatically and is different from the Astro/Starlight documentation.

## Astro documentation

The project documentation has its own `package.json` in:

```text
documentation/
```

To install its dependencies:

```bash
cd documentation
npm install
```

To run the documentation locally:

```bash
npm run dev
```

This command starts the Astro server used to view and edit the documentation during development.

## Build the Astro documentation

From the `documentation/` folder:

```bash
npm run build
```

This command generates the static documentation version in:

```text
documentation/dist/
```

This version is used during deployment to Firebase Hosting.

## Automatic deployment

Application and documentation deployment is automated with GitHub Actions.

When a relevant change is pushed to `main`, configured workflows can:

1. install dependencies;
2. build the related project;
3. retrieve generated files;
4. deploy them to the matching Firebase Hosting target.

Dear Pages uses two separate Firebase Hosting targets:

```text
app  → React application
docs → Astro + Starlight documentation
```

The application and documentation can therefore be deployed separately.

## Two npm projects

Dear Pages contains two distinct npm environments:

```text
DearPages/
├── package.json
│   └── React + Vite application
│
└── documentation/
    └── package.json
        └── Astro + Starlight documentation
```

Commands must be run from the folder that matches the project you want to use.

:::tip
Before running an npm command, checking the current folder helps avoid running a documentation script in the main application, or the reverse.
:::
