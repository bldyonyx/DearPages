Dear Pages uses several **npm** scripts for development, verification, and documentation. The main application's commands are defined in the root `package.json`.

## Start the development server

```bash
npm run dev
```

Starts the Vite development server with automatic reload when the source code changes.

## Build the application

```bash
npm run build
```

Generates the production build in `dist/`. It also verifies that the application can be built without blocking errors.

## Preview the build

```bash
npm run preview
```

Runs the production build generated by `npm run build` locally.

## Check code with Oxlint

```bash
npm run lint
```

Runs **Oxlint**, the static analysis tool used by Dear Pages. It reports potential errors and warnings, including warnings related to React patterns.

The root script is:

```json
"lint": "oxlint"
```

A warning is not necessarily a blocking error. Its impact should be assessed before making changes.

## Run automated tests

Dear Pages uses **Vitest** and **React Testing Library** to test services, utilities, selected React components, and important behavior.

To start Vitest in interactive mode:

```bash
npm run test
```

To run the complete test suite once, especially before deployment:

```bash
npm run test:run
```

The latter runs `vitest run`.

Automated tests complement manual user-flow checks; they do not replace them.

## Generate JSDoc documentation

```bash
npm run docs
```

The `jsdoc src -r -d docs` script processes JSDoc comments in `src/` and generates technical documentation in `docs/`.

This generated folder is separate from the Astro/Starlight documentation website.

## Astro and Starlight documentation

The documentation has its own npm project in `documentation/`.

```bash
cd documentation
npm install
npm run dev
```

To generate the static website, run the following from `documentation/`:

```bash
npm run build
```

The output is created in `documentation/dist/` and can be deployed to Firebase Hosting.

## Automatic deployment

GitHub Actions workflows build and deploy the application and documentation to two separate Firebase Hosting targets:

```text
app  → React application
docs → Astro + Starlight documentation
```

The relevant workflows can install dependencies, build the project, and publish generated files when changes are pushed to `main`.

## Two npm environments

```text
DearPages/
├── package.json           → React + Vite application
└── documentation/
    └── package.json       → Astro + Starlight documentation
```

:::tip
Always check your current directory before running an npm command: the application and documentation use independent scripts.
:::
