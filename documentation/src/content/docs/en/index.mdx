## Technical stack

Dear Pages is built with:

- **React** for the user interface
- **JavaScript** for application logic
- **Tailwind CSS** for styling and responsive behavior
- **Vite** for the development environment and build
- **React Router** for application navigation and routes
- **i18next** and **react-i18next** for the French / English bilingual interface
- **Google Books API** to search for and retrieve book information
- **Open Library** as a complementary source for books, trends, and covers
- **Google Cloud Translation API** to translate book descriptions into French or English
- **Firebase Authentication** for user authentication
- **Firebase Realtime Database** for personal data, the library, collections, and preferences
- **Vitest** and **React Testing Library** for automated tests
- **Firebase Hosting** to deploy the application and its documentation
- **GitHub Actions** to automate builds and deployments
- **JSDoc** to document important functions and services
- **Astro + Starlight** for this documentation

## Project status

Dear Pages has reached its first complete version.

The main features are implemented: authentication, onboarding, a French / English bilingual interface, book discovery, personalized recommendations, personal library, reading statuses, collections, notes, reviews, preferences, and annual reading goal.

The application also has automated tests with Vitest and React Testing Library and has been manually checked across its main user flows and display formats.

The application and its documentation are deployed separately with Firebase Hosting and updated automatically through GitHub Actions.
